## Návod na setup

1. Composer.phar se stáhne z [Daunload Kompouzeru](https://getcomposer.org/download/) <-- tady dole z latest stable
2. narvat to do PHP v xampp složce
3. nalinkovat nějak php složku a composer v phpstormu
4. na něco k composer
   ```bash
   php C:\xampp\php\composer.phar install
   ```
5. na React
   ```bash
   npm isntall 
   ```
6. nějaky encryption key, aby nebyly problemy potom to řvalo na mě se mi nelibilo
   ```bash
   php artisan key:generate 
   ```
7. ```bash
   php artisan migrate
   ```
8. nastavit .env soubor hlavně se prostě ujistit, že tam je mysql místo sqlite

All security vulnerabilities will be promptly addressed.
